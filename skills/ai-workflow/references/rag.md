## Existing repo
- How to recognise it: `langchain-postgres`, `pgvector`, Chroma, FAISS, Pinecone or Qdrant clients, a `retriever` object, an ingestion script that chunks and embeds, or a `retrieve` node in a graph.
- Rule: keep the existing vector store, embedding model and chunking; add contextual retrieval, reranking or citations on top. Changing the embedding model means re-embedding everything, so never do it unasked.

## New repo default
- First ask whether retrieval is needed. Anthropic's contextual-retrieval post says a knowledge base under 200,000 tokens (about 500 pages) can go whole into the prompt, and prompt caching makes that cheap. Retrieve only for larger corpora.
- Store: pgvector (`CREATE EXTENSION vector;`) through `langchain-postgres` (`PGEngine`, `PGVectorStore`). pgvector offers HNSW and IVFFlat indexes; HNSW queries faster but builds slower and uses more memory.
- Embeddings: Anthropic offers no embedding model; its docs point to Voyage AI (`voyage-4` balanced, `voyage-4-large` best quality, `voyage-4-lite` cheapest). Set `input_type` to `document` or `query`; never omit it. Rerankers: `rerank-3`.
- Contextual retrieval: before embedding and BM25 indexing, prepend a short chunk-specific context (generated by a small-tier model from the whole document) to each chunk. Reported top-20 retrieval failure rate: 5.7% baseline, 3.7% with contextual embeddings, 2.9% with BM25 added, 1.9% with reranking added. Cache the document in the prompt to cut generation cost.
- Pipeline: chunk, contextualize, embed, store; at query time run vector and BM25 search, merge, rerank, pass the top chunks.
- Citations: put sources in `document` blocks with `"citations": {"enabled": true}`; answers return `char_location`, `page_location` or `content_block_location` citations. Citations cannot be combined with structured outputs (`output_config.format` returns a 400).
- Retrieved text is untrusted data, never instructions; defences are in the guardrails reference.

```python
from langchain_core.documents import Document
from langchain_postgres import PGEngine, PGVectorStore

CTX = ("Here is a chunk from the document above:\n<chunk>\n{chunk}\n</chunk>\n"
       "Write one or two sentences situating this chunk within the document to improve "
       "search retrieval. Answer with the context only.")

async def contextualize(client, doc: str, chunk: str) -> str:  # client = AsyncAnthropic()
    resp = await client.messages.create(
        model=settings.MODEL_SMALL, max_tokens=1024,  # from app settings; thinking shares it
        messages=[{"role": "user", "content": [
            {"type": "text", "text": f"<document>\n{doc}\n</document>",
             "cache_control": {"type": "ephemeral"}},  # same doc for every chunk: cache hit
            {"type": "text", "text": CTX.format(chunk=chunk)}]}],
    )
    text = next((b.text for b in resp.content if b.type == "text"), "")
    return f"{text}\n\n{chunk}"

async def ingest(client, embeddings, db_url: str, doc: str, chunks: list[str], source: str):
    engine = PGEngine.from_connection_string(url=db_url)  # postgresql+asyncpg://...
    store = await PGVectorStore.create(
        engine=engine, table_name="chunks", embedding_service=embeddings
    )  # table made earlier via engine.ainit_vectorstore_table(...)
    docs = [Document(page_content=await contextualize(client, doc, c), metadata={"source": source})
            for c in chunks]
    await store.aadd_documents(docs)
```

## Avoid
- Retrieval for a corpus that fits in context → extra moving parts and lost passages → put it in the prompt with caching.
- Embedding bare chunks → a chunk like "revenue grew 3%" loses its company and period → prepend chunk-specific context first.
- Embeddings only → misses exact terms and ids → add BM25 and a reranker.
- Omitting `input_type` on Voyage embeddings → worse retrieval → set `document` for chunks and `query` for questions.
- Mixing embedding models in one index → vectors are not comparable → re-embed the whole index when the model changes.
- Pasting retrieved text into the system prompt → injected instructions gain authority → keep it in the user turn inside tags, as data.
