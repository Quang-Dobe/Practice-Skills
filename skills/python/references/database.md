# Database

> Load when: database tables, SQLAlchemy, ORM models, queries, sessions, Alembic, migrations. Pinned: Python 3.14, uv 0.12, ruff 0.16, mypy 2.4, pytest 9, pydantic 2.13, FastAPI 0.142, SQLAlchemy 2.1.

## Existing repo
- Recognise it: `sqlalchemy` in dependencies, `alembic.ini` + `alembic/` (or `migrations/`) with `env.py`, `declarative_base()` or `DeclarativeBase`, `Column(...)` models, `session.query(...)`, or other tools (Tortoise, Peewee, raw drivers).
- Rule: follow what is there. Keep legacy `Column` / `Query` code and the repo's migration tool; never migrate models unasked. Match the sync or async style already in use.

## New repo default
- SQLAlchemy 2.x ORM style: `class Base(DeclarativeBase)`, typed attributes `Mapped[...] = mapped_column(...)`; queries via `select()` with `session.scalars(...)` / `session.execute(...)`.
- Async: install `sqlalchemy[asyncio]` and an async driver (the example's `sqlite+aiosqlite` needs `aiosqlite`) (as of 2.1 greenlet is not included by default); `create_async_engine`, `async_sessionmaker(engine, expire_on_commit=False)`, `AsyncSession`. The docs advise `expire_on_commit=False` because attribute access after commit would trigger a lazy load, which cannot run implicitly in asyncio.
- Avoid lazy loads in async: `selectinload()`, or `lazy="raise"` to catch them. Call `await engine.dispose()` on shutdown.
- One session per unit of work (one request, one job), opened with a context manager; never share a session between threads or asyncio tasks.
- Alembic: `alembic init --template async alembic` (async engine; `generic` for sync); set `target_metadata = Base.metadata` in `env.py`.
- Migrate with `alembic revision --autogenerate -m "msg"`, then `alembic upgrade head`. Autogenerate only proposes: review every file (renames show as drop + add, unnamed constraints are missed).

```python
from sqlalchemy import String, select
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class Base(DeclarativeBase):
    pass


class User(Base):
    __tablename__ = "user_account"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(30))


engine = create_async_engine("sqlite+aiosqlite:///app.db")
session_factory = async_sessionmaker(engine, expire_on_commit=False)


async def add_user(name: str) -> User:
    async with session_factory.begin() as session:  # commits on exit
        user = User(name=name)
        session.add(user)
    return user


async def find_user(session: AsyncSession, name: str) -> User | None:
    return (await session.scalars(select(User).where(User.name == name))).first()
```

## Avoid
- Legacy `session.query(...)` in new code → the docs mark `Query` legacy since 2.0 (still works) → `select()`.
- One `AsyncSession` shared across `asyncio.gather` tasks → not safe for concurrent tasks → one session per task.
- Default `expire_on_commit` with async → attribute access after commit tries a lazy load → `expire_on_commit=False` plus explicit eager loading.
- Applying an autogenerated migration unread → missed renames or constraints → read and edit it first.
- Global long-lived session → stale state and leaked transactions → session per unit of work.
